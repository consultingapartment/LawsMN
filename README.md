# Монгол Улсын хуулийн сан (legalinfo.mn)

Хүчин төгөлдөр хуулиудыг [legalinfo.mn](https://legalinfo.mn)-ээс Word хэлбэрээр татаж, SQLite санд бүртгэнэ. Сар бүр дахин ажиллахад:

- өмнө байгаагүй **шинэ хууль** гарвал татна
- нэр, огноо, эсвэл Word файлын агуулга (**SHA-256**) өөрчлөгдсөн бол тухайн хуулийг **дахин татна**
- жагсаалтаас алга болсон хуулийг устгахгүй, `inactive` гэж тэмдэглэнэ
- нэрэнд «ХҮЧИНГҮЙ БОЛСОНД ТООЦОХ» орсон актуудыг хасна

## Суулгах

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Ажиллуулах

```bash
python sync_laws.py                 # бүтэн синк (эхний удаа бүгдийг татна)
python sync_laws.py --limit 5       # туршилт
python sync_laws.py --metadata-only # зөвхөн шинэ + нэр/огноо өөрчлөгдсөн
python sync_laws.py --force         # бүгдийг дахин татах
```

Үр дүн:

| Файл | Агуулга |
|---|---|
| `data/laws.sqlite` | хуулийн бүртгэл, өөрчлөлтийн түүх |
| `data/laws/*.doc` | Word файл (сайт HTML-Word буцаадаг) |
| `data/last_sync.json` | сүүлийн синкийн товч |

Word файлыг `POST https://legalinfo.mn/mn/wordExport` (`fileid`, A4 тохиргоо) гэж татна. Энгийн GET линк хоосон загвар буцаадаг тул скрипт өөрөө татна.

`sync_events` хүснэгт: `new`, `updated`, `unchanged`, `missing`, `failed`.

## GitHub дээр сар бүр

`.github/workflows/monthly.yml` сар бүрийн 1-нд ажиллана. Repo → Settings → Actions → General дээр **Read and write permissions** нээх хэрэгтэй, эс бөгөөс commit push хийхгүй.

Анхаарах зүйл: ~700 Word файл GitHub-ийн хэмжээний хязгаарт багтах боловч repo хурдан томорно. Word файлыг repo-д бүү оруул гэж үзвэл `.gitignore`-д `data/laws/` нэмээд, workflow дотор `git add -A data`-г `git add data/laws.sqlite data/last_sync.json` болго.

## Хэрхэн өөрчлөлт таньдаг вэ

1. Идэвхтэй хуулийн жагсаалтыг (`category=27`, `active=1`) бүхэлд нь уншина.
2. `law_id` санд байхгүй бол **шинэ** — Word-ыг татна.
3. Байгаа хууль дээр «Нэмэлт өөрчлөлт» табын **батлагдсан огноог** уншина. Хамгийн сүүлийн огноо өмнөхөөс шинэ бол (эсвэл таб дээр мөр нэмэгдсэн бол) зөвхөн тэр хуулийн Word-ыг дахин татна.
4. Огноо хэвээр бол файл татахгүй.
5. Эхний удаа огноо хадгалаагүй байсан файл дээр зөвхөн огноог тэмдэглээд, дахин татахгүй.

Word файлын SHA-256-г мөн хадгална, гэхдээ сар бүр бүх файлыг дахин татаж харьцуулахгүй. Таб дээр шинэ мөр гараагүй засагдал (зөвхөн найруулгын засвар) энэ аргаар анзаарагдахгүй. Тийм үед `python sync_laws.py --force`.

Серверийг ачаалахгүйн тулд жагсаалтын хуудас хооронд 0.6 сек, таб шалгалт 0.35 сек, файл таталт 1.2 сек завсарлагатай.
