# Монгол Улсын хуулийн сан (legalinfo.mn)

Хүчин төгөлдөр хуулиудыг [legalinfo.mn](https://legalinfo.mn)-ээс татаж, цэвэр текст (`legal/*.txt`) болгон хадгалж, SQLite санд бүртгэнэ. Сар бүр дахин ажиллахад:

- өмнө байгаагүй **шинэ хууль** гарвал татна
- «Нэмэлт өөрчлөлт» табын жагсаалт, эсвэл нэр/огноо/эмхэтгэл өөрчлөгдсөн бол тухайн хуулийг **дахин татна**
- жагсаалтаас алга болсон хуулийг устгахгүй, `inactive` гэж тэмдэглэнэ
- нэрэнд «ХҮЧИНГҮЙ БОЛСОНД ТООЦОХ» орсон актуудыг хасна

## Суулгах

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Ажиллуулах

```bash
python sync_laws.py                 # бүтэн синк (эхний удаа бүгдийг татна)
python sync_laws.py --limit 5       # туршилт
python sync_laws.py --metadata-only # табыг шалгахгүй: зөвхөн шинэ + нэр/огноо өөрчлөгдсөн
python sync_laws.py --force         # бүгдийг дахин татах
```

Үр дүн:

| Файл | Агуулга |
|---|---|
| `data/laws.sqlite` | хуулийн бүртгэл, өөрчлөлтийн түүх |
| `legal/*.txt` | хуулийн текст (`{lawId}_{нэр}.txt`) |
| `data/last_sync.json` | сүүлийн синкийн товч |

Текстийг `POST https://legalinfo.mn/mn/wordExport` (`fileid`, A4 тохиргоо) хариунаас гаргаж авна. Энгийн GET линк хоосон загвар буцаадаг тул скрипт өөрөө татна.

`sync_events` хүснэгт: `new`, `updated`, `unchanged`, `missing`, `failed`, `check_failed` (табыг уншиж чадаагүй), `baseline`, `missing_guard`.

## GitHub дээр сар бүр

`.github/workflows/monthly.yml` сар бүрийн 1-нд ажиллана. Repo → Settings → Actions → General дээр **Read and write permissions** нээх хэрэгтэй, эс бөгөөс commit push хийхгүй.

`sync-to-drive.yml` нь хуулийн синк амжилттай дууссаны дараа автоматаар ажиллаж `legal/*.txt`-г Google Drive руу хуулна.

## Хэрхэн өөрчлөлт таньдаг вэ

1. Идэвхтэй хуулийн жагсаалтыг (`category=27`, `active=1`) бүхэлд нь уншина. Жагсаалт дуусаагүй эсвэл өмнөхөөс 10%-иас их буурсан бол сайтын доголдол гэж үзэж хуулийг `inactive` болгохгүй.
2. `law_id` санд байхгүй бол **шинэ** — текстийг татна.
3. Нэр, огноо, эмхэтгэл өөрчлөгдсөн бол дахин татна.
4. Бусад үед «Нэмэлт өөрчлөлт» табын жагсаалтын хэшийг өмнөхтэй харьцуулна. Өөр бол дахин татна. Нэмэлт өөрчлөлтгүй хуулийн хуудсанд таб байхгүй тул «0 нэмэлт» гэж тэмдэглэнэ — анх нэмэлт орох үед дахин татагдана.
5. Табыг уншиж чадаагүй бол `check_failed` гэж бүртгэж, дараагийн удаа дахин шалгана.

Таб дээр шинэ мөр гараагүй засагдал (зөвхөн найруулгын засвар) энэ аргаар анзаарагдахгүй. Тийм үед `python sync_laws.py --force`.

Серверийг ачаалахгүйн тулд жагсаалтын хуудас хооронд 0.6 сек, таб шалгалт 0.35 сек, файл таталт 1.2 сек завсарлагатай.
